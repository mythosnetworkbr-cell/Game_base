# NYX ROLEPLAY

Gamemode oficial da NYX Roleplay / Mythøs Network.

## Arquitetura

- `gamemodes/nyx_roleplay.pwn` — núcleo inicial da gamemode
- Sistemas serão separados em módulos conforme a evolução do projeto.

## Sistemas iniciais

- Login e registro
- Criação/seleção de personagem
- Skins
- Economia inicial
- Organizações
- Status de organizações ATIVA/OFFLINE
- Cargos/ranks
- GPS
- Status do personagem
- Central de ajuda

## Organizações

1. Polícia Militar
2. Polícia Civil
3. SAMU
4. Mecânicos
5. Governo
6. Jornal NYX
7. Ballas
8. Families
